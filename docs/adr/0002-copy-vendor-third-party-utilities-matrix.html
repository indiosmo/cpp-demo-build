ADR-0002: dependency management decision matrix

Companion to ADR-0002. The project uses a small set of header-only utilities. The decision is how those utility headers enter a self-contained C++ lab.

Assumptions

  • Utility size: the dependencies are small header-only libraries.
  • Local setup: a fresh checkout should configure and build without fetching project utility sources.
  • Audit trail: copied bytes should carry origin, version, selected paths, and license text.
  • Project vocabulary: domain code should consume utility concepts through lab:: aliases where useful.
Criterion A. Copy-vendor Commit selected headers under vendor/<name>/upstream/. B. Git submodules Track each upstream as a pinned submodule. C. CMake FetchContent Fetch each upstream during configure. D. ExternalProject Download and expose dependencies through external project steps.
Fresh checkout Headers are present immediately. Needs recursive clone or submodule initialization. First configure depends on network and cache state. First build depends on external download steps.
Reproducibility Exact built bytes are committed. SHA is pinned, but source retrieval is external. SHA can be pinned, but retrieval is external. URL and SHA can be pinned, but retrieval is external.
Setup cost Copy headers, metadata, license, and one interface target. Small, plus checkout discipline. Small CMake blocks, plus fetch flags and cache behavior. Too much machinery for header-only utilities.
License review License text lives beside copied bytes. License text is in the submodule checkout. License text appears after fetch. License text appears after download.
Update ergonomics Manual recopy and metadata update. Bump the gitlink SHA. Bump the fetched SHA. Bump the external project URL or SHA.
CMake complexity One INTERFACE target per utility. Comparable, plus guards for uninitialized submodules. Modern, but each dependency needs careful options. Download, dependency-edge, and include-export plumbing.

Decision

Decision: A. Copy-vendor. For small header-only utilities, committing selected headers under vendor/ gives the clearest clone, audit, and build story. Manual updates are accepted because the utility set is small.
